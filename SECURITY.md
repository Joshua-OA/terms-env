# Security policy

## Reporting a vulnerability

Email the maintainers directly (see GitHub repo owners) or open a GitHub
Security Advisory. Please do not open public issues for vulnerabilities.

We aim to acknowledge within 72 hours and will credit reporters in release
notes unless anonymity is requested.

## Supported versions

| Version | Supported |
|---|-------|
| 0.1.x   | ✅    |

## Design documentation

Read [docs/threat-model.md](docs/threat-model.md) before reporting — it lists
explicit non-goals so we can focus feedback on real gaps.
